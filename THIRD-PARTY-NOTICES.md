# Заимствования

Inkwright распространяется по лицензии MIT. Ниже перечислено то, что взято у других проектов, и
условия, на которых это сделано.

## pdf.js (Mozilla Foundation), Apache License 2.0

<https://github.com/mozilla/pdf.js>

Портированы на C# следующие алгоритмы. Это переписанный код, а не скопированный: структура и
поведение сохранены, реализация своя.

| Что | Откуда | Куда |
| --- | --- | --- |
| Чтение двоичного формата CMap | `src/core/binary_cmap.js` | `src/Inkwright.Cjk/BinaryCMapReader.cs` |
| Двунаправленный алгоритм (подмножество UAX #9) и таблицы классов | `src/core/bidi.js` | `src/Inkwright/Text/Bidi.cs` |
| Правила нормализации текста при поиске | `web/pdf_find_controller.js` | `src/Inkwright/Text/TextNormalizer.cs` |
| Семантика встроенных форматирующих скриптов Acrobat | `src/scripting_api/aform.js` | `src/Inkwright.Forms/FieldFormat.cs`, `FieldCalculation.cs` |
| Перечень того, что переносится при слиянии документов | `src/core/editor/pdf_editor.js` | `src/Inkwright/Merging/` |

Текст лицензии: <https://www.apache.org/licenses/LICENSE-2.0>

## Adobe CMap Resources, BSD 3-Clause

<https://github.com/adobe-type-tools/cmap-resources>

Пакет `Inkwright.Cjk` содержит 168 предопределённых CMap таблицы 118 ISO 32000 в компактном
двоичном виде, в котором их публикует pdf.js. Полный текст лицензии Adobe лежит рядом с ними:
`src/Inkwright.Cjk/cmaps/LICENSE-ADOBE-CMAP.txt`.

## Спецификации

Таблицы метрик четырнадцати стандартных шрифтов и таблицы кодировок Annex D построены из
опубликованных Adobe метрик AFM и из текста ISO 32000-1.

Ничто из перечисленного ниже не скопировано из кода: это реализации по нормативному тексту, где
таблицы значений транскрибированы из печатных таблиц стандарта.

| Что | По какому нормативу |
| --- | --- |
| Формат файла, PDF 1.7 и 2.0 | ISO 32000-1:2008; ISO 32000-2:2020 (второе издание, Errata Collection 3) |
| Профили PDF/A | ISO 19005-1, -2, -3 с корригендумами |
| Профили PDF/UA | ISO 14289-1:2014, ISO 14289-2:2024; пространства имён — ISO/TS 32005 |
| Обмен данными форм и аннотаций | ISO 19444-1:2016 |
| Факсовые кодировки: таблицы 2, 3a, 3b, 4, 5 и режимы | ITU-T T.4 (07/2003), ITU-T T.6 |
| JBIG2: арифметический декодер Annex E, таблица E.1, generic-регион §6.2, сегменты §7.2 | ITU-T T.88 (08/2018), он же ISO/IEC 14492:2019 |
| Compact Font Format и обход charstring | Adobe Technical Note #5176, #5177 |
| AES-GCM в PDF | ISO/TS 32003:2023; режим — NIST SP 800-38D |
| Дайджесты SHA-3 и SHAKE256 в подписях | ISO/TS 32001:2022; сами функции — FIPS PUB 202 |
| Кривые Эдвардса в подписях | ISO/TS 32002:2022; IETF RFC 8032, 8410, 8419 |
| Защита целостности | ISO/TS 32004:2024; RFC 2104, 3394, 5652, 5869 |
| Объявления соответствия | PDF Association, PDF Declarations (2019); Well-Tagged PDF 1.0 |
| Ассоциированные файлы, метаданные объектов, компенсация чёрной точки | PDF 2.0 Application Notes 002, 003, 001 |

Транскрибированные таблицы кодов ITU-T T.4 сверены с эталонной реализацией, опубликованной вместе с
ITU-T T.88 (`JBIG2_SampleSoftware`); арифметический декодер JBIG2 сверен с тест-вектором Annex H.2,
а таблицы Хаффмана Annex B — с рабочим примером B.4 и проверкой на префиксность. Развёртывание ключа
сверено с тест-вектором RFC 3394 §4.6.
